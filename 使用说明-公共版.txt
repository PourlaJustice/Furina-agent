芙宁娜桌宠 · 公共纯净版使用说明
================================

【这是什么】
本包为「纯净版」：已移除所有个人 API Key、账号 Cookie、语音克隆数据、
聊天记录等个人数据。包内模型、浏览器、播放器、便携 Node 均已内置，
解压后无需安装任何软件即可运行。

【第一步：填写你自己的 API Key（必需）】
双击打开 mcp-servers.json（可用记事本），把里面的占位符替换成你自己的 Key：
- DeepSeek / 其他模型：聊天面板 ⚙ 设置 → 对话模型设置（或环境变量）
- 和风天气：qweather 条目 QWEATHER_API_KEY 与 QWEATHER_API_BASE
- 视觉理解：qwen-vision 条目 DASHSCOPE_API_KEY
- 语音朗读/语音输入：⚙ 设置 → 语音 中填写 MiniMax 与阿里云百炼 Key
不改也可以聊天，但天气、看图、语音等服务会提示未配置。

【第二步：启动】
双击「一键启动.bat」，等待几秒，芙宁娜出现在桌面右下角。
关闭桌宠：双击「关闭桌宠.bat」。

【网易云音乐】
本包不含任何登录状态。第一次使用点歌时，按提示在浏览器登录网易云
并导入 Cookie 即可（服务会引导你完成）。

【安全提示】
- 请勿把自己的 Key 提交到公开仓库或分享给陌生人
- mcp-servers.json 里的占位符不会影响运行，填入真实 Key 后即生效
