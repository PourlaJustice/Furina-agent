芙宁娜桌宠 · 全量开发包使用说明
================================

【这是什么】
这是一个包含全部内容的芙宁娜桌宠项目：源码、依赖（node_modules）、
Live2D 模型、内置便携版 Node 24、Playwright 浏览器、网易云音乐播放器、
以及各项服务的密钥配置。解压后无需安装任何软件即可运行和开发。

【怎么启动】
1. 解压整个压缩包到任意位置（路径建议不要包含特殊符号）。
2. 双击「一键启动.bat」。
3. 等待几秒，芙宁娜会出现在桌面右下角。
4. 想关闭桌宠：双击「关闭桌宠.bat」。

【日常开发】
- 修改源码后，双击「一键启动.bat」即可重新编译并启动（会自动 npm run dev）。
- 首次启动会自动重新构建，稍慢是正常的。
- 如果电脑已自行安装 Node.js 24，删除 node-portable 文件夹也可正常使用系统 Node。

【内置服务说明】
- SQLite 数据库：项目 data/furina.db（聊天记录、统计）
- 和风天气：mcp-servers.json 中的 qweather（含 API Key）
- 视觉理解：qwen-vision（含百炼 DashScope Key）
- 文件系统 / 浏览器（Playwright，已内置 Chromium）/ 网易云音乐（已内置 mpv）
- 所有服务均为本地启动，不依赖网络下载。

【安全提示（重要）】
- 本包内含 API 密钥、网易云账号 Cookie 等个人凭据，只可发给信任的开发者，
  请勿上传公开平台或网盘公开分享。
- 如果收件人不需要某个服务，可以在 mcp-servers.json 里把对应条目
  "enabled" 改为 false。
- 天气/视觉密钥在控制台可随时重置；收到包的人改 mcp-servers.json 即可换新 Key。

【常见问题】
- 启动失败/无窗口：检查杀毒软件或 360 是否拦截了 electron.exe 和 mpv.exe，
  加入信任列表后重试。
- 端口被占用：重启电脑或关闭占用 5173 端口的程序。
- 想完全重新构建：删除 dist 文件夹后重新「一键启动」。
- 同步开发：建议配合 GitHub 仓库使用（本包不含 .git 历史）。
